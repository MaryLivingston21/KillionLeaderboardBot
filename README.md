# Krillion Puzzle 🦐

Discord leaderboard bot for the [Krillion puzzle](https://playlin.io/game/krillion/).

## Commands

- `/leaderboard` — View today's leaderboard privately
- `/leaderboard date:MM/DD/YYYY` — View a previous leaderboard privately
- `/sync` — Sync today's Krillion scores from server messages
- `/leaderboard_auto enabled:On/Off` — Enable or disable the nightly public leaderboard
- `/leaderboard_auto_channel channel:#channel` — Set the channel for the nightly leaderboard
- `/help` — Show available commands

The nightly leaderboard is posted publicly at **11:59 PM Eastern** when enabled.
